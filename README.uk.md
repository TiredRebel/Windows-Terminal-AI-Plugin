# TerminalAI — помічник Ollama для PowerShell і Windows Terminal

[English — canonical](README.md) | **Українська (переклад)** | [Допоміжний C#-модуль](AOT/README.uk.md)

TerminalAI — це модуль PowerShell для Windows, який надсилає запити на генерацію команд і чат до налаштованої кінцевої точки Ollama. Він допомагає створювати команди та сценарії, діагностувати помилки, вести інтерактивний діалог, інтегрується з Windows Terminal, виконує перевірки перед запуском і може запускати необов'язковий Claude Code.

Типове значення `OllamaUrl` — локальна адреса `http://localhost:11434`, тому основні запити за замовчуванням залишаються локальними. Адресу можна змінити, а агентний режим запускає окремо встановлений Claude Code CLI; перевірте ці налаштування, щоб розуміти фактичні межі даних. Інсталятор та інтерфейс застосунку доступні лише англійською. `Language` вибирає `en` або `uk` для текстових відповідей моделі, а не для інтерфейсу.

> [!IMPORTANT]
> Згенеровані моделлю команди є недовіреним введенням. Перевіряйте їх перед виконанням. AST-перевірки та попередній перегляд WhatIf є захисними бар'єрами, а не пісочницею. Команди виконуються з правами поточного користувача.

## Для кого призначений TerminalAI

TerminalAI призначений для користувачів Windows, які працюють із PowerShell і можуть перевіряти згенеровані команди, зокрема для:

- розробників і DevOps-інженерів, яким потрібна допомога з командами, сценаріями та діагностикою в терміналі;
- адміністраторів і фахівців підтримки, яким потрібні чернетки PowerShell із видимим етапом перевірки;
- тих, хто вивчає PowerShell і хоче отримувати команди разом із поясненнями;
- користувачів, які віддають перевагу локально налаштованій Ollama для основних функцій.

<!-- sync:advantages -->
## Переваги

- **Робота в терміналі:** створення команд і сценаріїв, діагностика помилок та чат із PowerShell або Windows Terminal.
- **Локально за замовчуванням:** основні запити можуть залишатися на комп'ютері, якщо `OllamaUrl` вказує на локальну Ollama; хмарний API-ключ для них не потрібен.
- **Перевірка перед виконанням:** аналіз, класифікація ризику, запити підтвердження та підтримуваний перегляд WhatIf відокремлюють відповідь моделі від запуску.
- **Вибір компонентів:** можна встановити всі продукти або вибрати Core, Ollama, Aot і WindowsTerminal. Aot та WindowsTerminal потребують Core.
- **Підтримка оболонок:** Core працює в PowerShell 7+ і Windows PowerShell 5.1; необов'язковий скомпільований модуль працює в PowerShell 7+ із .NET 10.
- **Діагностика:** `ai-doctor` перевіряє модуль, профіль, інтеграцію з терміналом, Ollama, вибрану модель, захисні функції та необов'язковий агентний режим.

## Вимоги

**ОС:** Windows 10 20H2+ або Windows 11. Встановлення для поточного користувача не потребує прав адміністратора; `-Scope AllUsers` потребує. Продукт Ollama встановлюється на рівні системи незалежно від цього параметра.

| Продукт | Оболонка | Додаткова вимога |
| --- | --- | --- |
| **Core** — `ai`, `ai-fix`, `ai-script`, `ai-chat`, `ai-doctor` | Рекомендовано PowerShell 7+; також Windows PowerShell 5.1 | — |
| **Ollama** — виявлення, необов'язкове встановлення, налаштування моделі | Будь-яка | Інтернет для першого завантаження; кілька ГБ на модель; GPU необов'язковий |
| **Aot** — керований допоміжний модуль .NET 10, `aif` / `ai-fast` | PowerShell 7+ | Сумісне середовище .NET 10; Core має бути вже встановлено |
| **WindowsTerminal** — профілі та дії фрагмента | Будь-яка | [Windows Terminal](https://aka.ms/terminal) 1.18+; Core має бути вже встановлено |

Типова модель — `qwen2.5-coder:7b`; для систем із меншою доступною пам'яттю можна вибрати `qwen2.5-coder:3b`. Для `ai-agent` додатково потрібен окремо встановлений Claude Code CLI.

## Встановлення

Підтверджений канал випуску — GitHub Releases:

- [Завантажити `TerminalAI-v0.1.0-preview1-win-x64.zip`](https://github.com/TiredRebel/Windows-Terminal-AI-Plugin/releases/download/v0.1.0-preview1/TerminalAI-v0.1.0-preview1-win-x64.zip)
- [Нотатки до випуску `v0.1.0-preview1`](https://github.com/TiredRebel/Windows-Terminal-AI-Plugin/releases/tag/v0.1.0-preview1)

Публічним каналом досі є старіший `v0.1.0-preview1`. Preview2 у цьому репозиторії є неопублікованим кандидатом на випуск і не має публічного посилання на завантаження.

Бінарні файли preview наразі не підписані. Підписування та перевірка підпису є воротами випуску, а не функціями цього preview.

> [!IMPORTANT]
> Для встановлення використовуйте версійний файл у розділі **Releases**. Автоматично створені GitHub архіви вихідного коду не є інсталяторами.

Розпакуйте архів, відкрийте PowerShell у цьому каталозі та виконайте:

```powershell
pwsh -ExecutionPolicy Bypass -File .\Install-TerminalAi.ps1
. $PROFILE
```

У Windows PowerShell 5.1 замініть `pwsh` на `powershell.exe`. Типово встановлюються всі чотири продукти. Щоб вибрати продукти або початкову мову текстових відповідей моделі:

```powershell
pwsh -ExecutionPolicy Bypass -File .\Install-TerminalAi.ps1 -Products Core,Ollama -Language uk
```

Доступність у PowerShell Gallery і WinGet зараз не підтверджено. Не використовуйте команди встановлення з цих каналів до перевірки. Також доступні встановлення з вихідного коду та тимчасовий завантажувач:

```powershell
git clone https://github.com/TiredRebel/Windows-Terminal-AI-Plugin.git
cd Windows-Terminal-AI-Plugin
pwsh -ExecutionPolicy Bypass -File .\Install-TerminalAi.ps1

# Перегляньте віддалений код, перш ніж передавати його PowerShell.
irm https://raw.githubusercontent.com/TiredRebel/Windows-Terminal-AI-Plugin/main/bootstrap.ps1 | iex
```

У [технічному посібнику для супровідників](docs/TECHNICAL.md#installation-details) наведено всі параметри інсталятора та команди для окремих продуктів.

### Тимчасовий портативний сеанс

Запустіть `bootstrap.ps1 -Mode Portable`, щоб завантажити модуль у поточний процес PowerShell без оновлення профілю поточного користувача або наявної конфігурації TerminalAI. Вибір мови діє лише в цьому процесі. Якщо bootstrap завантажує пакет runtime, розпаковані файли та інші тимчасові завантаження можуть залишитися в `$env:TEMP`; видаліть їх, коли вони більше не потрібні.

## Команди та робочі сценарії

| Команда | Призначення |
| --- | --- |
| `ai` / `??` | Згенерувати одну команду за допомогою реалізації PowerShell. |
| `aif` / `ai-fast` | Згенерувати одну команду за допомогою керованого модуля .NET 10 у PowerShell 7+. |
| `ai-fix` / `fix-error` | Діагностувати останню помилку PowerShell і запропонувати виправлення. |
| `ai-script` | Створити багаторядковий сценарій PowerShell і за потреби зберегти його. |
| `ai-chat` / `ai-assistant` | Запустити інтерактивний помічник з обмеженою історією. |
| `ai-agent` | Запустити Claude Code для налаштованої кінцевої точки. |
| `ai-doctor` | Перевірити встановлення та налаштовані служби. |
| `ai-help` | Показати вбудовану довідку. |

Приклади:

```powershell
ai "знайти файли розміром понад 100 МБ"
ai "показати відкриті TCP-порти" -Execute
ai "отримати адресу шлюзу" -Copy
ai "пояснити цей конвеєр" -Explain
ai-fix
ai-script "створити звіт про вільне місце" -OutputPath .\Get-DiskReport.ps1 -Edit
ai-doctor
```

У рядку PSReadLine введіть коментар і натисніть `F2`, `Ctrl+G` або налаштовану комбінацію `Ctrl+Alt+A`. TerminalAI замінить рядок згенерованим кодом PowerShell. Доступність комбінацій залежить від PSReadLine та активного консольного хоста.

`ai-script` захищає наявні файли переглядом відмінностей і запитом підтвердження; параметра `-Force` немає. Перевіряйте кожен згенерований шлях і команду.

## Інтерактивний помічник

```powershell
ai-chat
ai-chat -Model qwen2.5-coder:7b
```

Помічник використовує кінцеву точку Ollama `/api/chat`, зберігає обмежену FIFO-історію та маскує відомі шаблони перед додаванням повідомлень до історії. Така перевірка не може розпізнати кожен секрет.

| Слеш-команда | Дія |
| --- | --- |
| `/help`, `/?` | Показати довідку помічника. |
| `/models`, `/model <name>` | Переглянути або вибрати модель Ollama. |
| `/lang <en\|uk>` | Зберегти мову текстових відповідей моделі у `config.json` та оновити поточний процес. |
| `/lang permanent <en\|uk>`, `/lang-permanent <en\|uk>` | Зробити те саме й додатково записати користувацьку змінну `TERMINAL_AI_LANG`. |
| `/context`, `/reset` | Показати використання історії або очистити її. |
| `/inspect [clear]` | Показати діагностичний контекст або очистити запис останньої помилки. |
| `/run` | Передати останній блок коду шлюзу виконання. |
| `/read <path>` | Додати перевірений за розміром локальний текстовий файл до контексту. |
| `/copy` | Скопіювати останній блок коду; спочатку перевірте його на секрети. |
| `/save [path.ps1]` | Зберегти останній блок коду із захистом від перезапису. |
| `/clear`, `/exit` | Очистити екран або завершити сеанс. |

## Необов'язковий агентний режим

`ai-agent` запускає окремо встановлений Claude Code. TerminalAI спрямовує `ANTHROPIC_BASE_URL` на налаштовану адресу `OllamaUrl` і типово використовує `~/.terminal-ai/claude` як каталог даних.

```powershell
ai-agent -CheckOnly
ai-agent "перевір поточний git diff і запусти доречні тести"
ai-agent -WorkingDir C:\src\project -Model qwen2.5-coder:7b
ai-agent -Resume
ai-agent -Print "підсумуй цей проєкт"
```

Цільова система має підтримувати API, який очікує Claude Code, зокрема `/v1/messages`; перевірка кінцевих точок моделей Ollama не доводить цю сумісність. Claude Code зберігає власну модель дозволів і може читати, змінювати або запускати дозволений нею вміст.

## Керований допоміжний модуль .NET 10

У PowerShell 7+ Core може завантажити `TerminalAI.Aot.dll` і надати `Invoke-AiCommandFast` через аліаси `aif` та `ai-fast`.

```powershell
aif "знайти великі файли журналів"
aif "перезапустити службу Spooler" -Execute
aif "як конвеєри PowerShell передають об'єкти?" -Ask
```

`AOT` — це історична назва шляху та проєкту. Поточний проєкт `net10.0` створює керовану DLL командою `dotnet build` і не визначає `<PublishAot>`. Див. [посібник для C#-модуля](AOT/README.uk.md).

## Модель безпеки

Обидві реалізації аналізують згенерований PowerShell перед виконанням. Аналізатори розподіляють команди за дев'ятьма категоріями та чотирма рівнями ризику. Синтаксичні помилки блокуються; високий, критичний, динамічний або невизначений ризик потребує підтвердження.

Попередній перегляд WhatIf пропонується лише тоді, коли відповідні команди PowerShell підтримують `ShouldProcess`; TerminalAI не додає `-WhatIf` до довільних зовнішніх програм. Команди однаково виконуються в процесі та з правами поточного користувача.

Робота із секретами базується на шаблонах. Помічник маскує відомі шаблони перед додаванням повідомлень до історії, а C#-модуль — в окремих шляхах відображення та копіювання. Звичайні PowerShell-команди `ai -Copy` та `/copy` помічника копіюють згенерований блок без змін, тому перевіряйте його самостійно.

## Конфігурація та мова

Конфігурація зберігається у `~/.terminal-ai/config.json` або в каталозі `TERMINAL_AI_CONFIG_DIR`. Значення `TERMINAL_AI_LANG` має пріоритет над файлом для бажаної мови текстових відповідей моделі.

```powershell
Get-TerminalAiConfig
Set-TerminalAiConfig -Model qwen2.5-coder:7b -Temperature 0.2
Set-TerminalAiConfig -OllamaUrl http://localhost:11434 -TimeoutSeconds 120
Set-TerminalAiLanguage -Language uk
Set-TerminalAiLanguage -Language en -Permanent
```

Команда без `-Permanent` однаково зберігає `config.json` і оновлює поточний процес. `-Permanent` додатково записує користувацьку змінну `TERMINAL_AI_LANG` для майбутніх процесів. Текст застосунку залишається англійським.

## Інтеграція з Windows Terminal

Типово інсталятор копіює `terminalai.json` до каталогу фрагментів Windows Terminal і не змінює `settings.json`. Фрагмент додає два профілі та дії для `ai`, `ai-fix`, `ai-script` і спліт-панелі помічника. `-ModifySettingsJson` вмикає застарілий спосіб додавання дій після створення резервної копії.

```powershell
ai fonts
ai font "Cascadia Code"
Set-TerminalAiFont -Font "Cascadia Code" -Size 13
```

## Діагностика проблем

- **Немає з'єднання з Ollama:** виконайте `ollama list`; за потреби запустіть `ollama serve`, а потім перевірте `OllamaUrl` через `Get-TerminalAiConfig`.
- **Комбінація клавіш не працює:** виконайте `Import-Module TerminalAI -Force`, переконайтеся, що PSReadLine активний, і спробуйте `F2`.
- **Текст відображається неправильно:** використовуйте шрифт із підтримкою Unicode та UTF-8 для консолі; інсталятор додає налаштування UTF-8 до профілю.
- **Стан встановлення незрозумілий:** виконайте `ai-doctor` або `Test-TerminalAiInstallation -PassThru`.
