# TerminalAI.Aot — керований допоміжний модуль .NET 10 для PowerShell

[English — canonical](README.md) | **Українська (переклад)** | [Головний посібник](../README.uk.md)

`TerminalAI.Aot` — це скомпільований C#-модуль TerminalAI для PowerShell 7+ (`net10.0`). Він надає `Invoke-AiCommandFast` через аліаси `aif` і `ai-fast`, використовує спільну конфігурацію TerminalAI, звертається до Ollama через HTTP, аналізує згенерований PowerShell і може передавати агентні завдання модулю Core.

Інсталятор, картки стану, довідка, меню та повідомлення про помилки доступні лише англійською. `Language` вибирає бажану мову текстових відповідей моделі для `-Ask` і `-Explain`; цей параметр не локалізує інтерфейс або звичайну генерацію команд.

`AOT` — це історична назва шляху та проєкту. Поточний проєкт створює керовану DLL .NET 10 командою `dotnet build` і не визначає `<PublishAot>`.

> [!IMPORTANT]
> Згенеровані моделлю команди є недовіреним введенням. Перевіряйте їх перед виконанням. AST-перевірки та попередній перегляд WhatIf є захисними бар'єрами, а не пісочницею. Команди виконуються з правами поточного користувача.

<!-- sync:audience -->
## Для кого призначений цей компонент

Цей модуль призначений для користувачів TerminalAI, яким потрібна скомпільована реалізація на C#, і для супровідників, які збирають або тестують її. Потрібні PowerShell 7+ і .NET 10; Windows PowerShell 5.1 не підтримується. Модуль залежить від Core для спільної конфігурації та передавання агентних завдань.

<!-- sync:advantages -->
## Переваги

- **Скомпільована локальна обробка:** керування командами, HTTP-запити, AST-аналіз, консольний ввід і буфер обміну працюють у керованому модулі .NET 10; час відповіді моделі однаково залежить від Ollama, моделі та обладнання.
- **Спільна конфігурація:** C#- і PowerShell-реалізації використовують однакові налаштування TerminalAI та вибір моделі.
- **Захисні перевірки виконання:** перевірка синтаксису, класифікація ризику, підтвердження, підтримуваний перегляд WhatIf і шаблонне маскування секретів залишаються частиною процесу.
- **Захищене збереження сценаріїв:** доступні перегляд відмінностей, захист від перезапису та запис у UTF-8 із BOM.
- **Необов'язкове встановлення:** можна залишити PowerShell-реалізацію та встановити цей модуль лише на сумісних системах із PowerShell 7+.

## Вимоги

- Windows 10 20H2+ або Windows 11
- PowerShell 7+
- сумісне середовище .NET 10
- встановлений продукт TerminalAI Core
- доступна налаштована кінцева точка Ollama та модель

<!-- sync:install -->
## Встановлення та імпорт

Основний інсталятор встановлює Core перед продуктом Aot:

```powershell
pwsh -ExecutionPolicy Bypass -File .\Install-TerminalAi.ps1 -Products Core,Aot
```

Щоб зібрати й імпортувати проєкт із репозиторію:

```powershell
dotnet build .\AOT\TerminalAI.Aot.csproj -c Release
pwsh -NoProfile -Command "Import-Module .\AOT\bin\Release\net10.0\TerminalAI.Aot.dll -Force; Get-Command aif"
```

Якщо процес PowerShell уже завантажив DLL, Windows може не дозволити перезаписати цей файл. Перевіряйте нову збірку у свіжому процесі `pwsh -NoProfile`.

<!-- sync:usage -->
## Використання

```powershell
aif "знайти файли розміром понад 100 МБ"
aif "показати відкриті TCP-порти" -Execute
aif "отримати адресу шлюзу" -Copy
aif "знайти процеси, що використовують понад 1 ГБ" -Alias
aif "як конвеєри PowerShell передають об'єкти?" -Ask
aif "створити сценарій резервного копіювання" -SavePath .\backup.ps1
aif agent "перевір git diff і запусти доречні тести"
```

| Параметр | Аліаси | Призначення |
| --- | --- | --- |
| `-Prompt` | позиційний 0 | Запит або керівна підкоманда. |
| `-Model` | — | Модель Ollama для цього виклику. |
| `-Execute` | `-x`, `-y` | Передати згенерований код шлюзу виконання. |
| `-Copy` | `-c` | Скопіювати результат після обробки відомих шаблонів C#-санітизатором. |
| `-Explain` | — | Отримати структуроване пояснення. |
| `-Ask` | `-chat`, `-question` | Отримати текстову відповідь замість команди. |
| `-Agent` | `-Autonomous` | Передати завдання до `Invoke-AiAgent` із Core. |
| `-Alias` | `-a`, `-Short`, `-UseAliases` | Віддавати перевагу коротким аліасам PowerShell. |
| `-SavePath` | `-Save`, `-OutFile` | Зберегти результат із переглядом відмінностей і захистом від перезапису. |
| `-Force` | `-f` | Перезаписати наявний файл без запиту. |
| `-ConfirmInput` | — | Передати `y` або `n` шлюзу виконання, переважно для тестів. |

Керівні підкоманди: `models`, `model <name>`, `lang <en|uk>`, `status`, `config`, `help` і `agent <task>`. `lang` змінює мову текстових відповідей моделі, а не інтерфейсу.

Після генерації меню підтримує `Enter` для запуску через шлюз, `C` для копіювання, `I` для вставлення, `S` для перемикання аліасів, `W` для збереження, `X` для пояснення, `A` для текстового запитання та `Esc` для скасування.

<!-- sync:safety -->
## Модель безпеки

`AotCommandAstAnalyzer` розподіляє команди за категоріями `ReadOnly`, `SystemChange`, `Deletion`, `NetworkChange`, `ServiceOrProcess`, `Registry`, `DiskOrPartition`, `DynamicOrUnknown` та `ExternalProgram`. Рівні ризику: `Low`, `Medium`, `High` і `Critical`.

Синтаксичні помилки блокуються. Високий, критичний, динамічний або невизначений ризик потребує підтвердження. WhatIf використовується лише для команд PowerShell, які підтримують `ShouldProcess`; він не додається до довільних зовнішніх програм.

`AotSecretSanitizer` розпізнає окремі API-ключі, bearer-токени, параметри паролів і блоки приватних ключів перед окремими операціями відображення та копіювання. Це детермінований шаблонний фільтр, який не може виявити секрети невідомого формату.

<!-- sync:configuration -->
## Конфігурація та мова

Модуль читає `~/.terminal-ai/config.json` або каталог, вибраний через `TERMINAL_AI_CONFIG_DIR`. Основні параметри: `OllamaUrl`, `Model`, `Language`, `Temperature`, `TimeoutSeconds`, `UseAliases` і налаштування агента.

```powershell
aif status
aif models
aif model qwen2.5-coder:7b
aif lang uk
aif config
```

Повний опис конфігурації наведено в [технічному посібнику для супровідників](../docs/TECHNICAL.md#configuration-reference).

<!-- sync:limitations -->
## Обмеження

- Модуль використовує Win32 для буфера обміну й частини консольної взаємодії, тому призначений для Windows.
- `aif -Agent` потребує імпортованого модуля TerminalAI Core та окремо встановленого Claude Code CLI.
- Налаштована кінцева точка визначає межі даних.
- Час відповіді зазвичай визначається інференсом моделі; скомпільована локальна обробка не усуває ці витрати.
- PowerShell- і C#-шляхи є окремими реалізаціями, тому паритет поведінки потрібно перевіряти тестами.

<!-- sync:development -->
## Збирання та тести

```powershell
dotnet build .\AOT\TerminalAI.Aot.csproj -c Release

Get-ChildItem .\AOT\tests\*.Tests.ps1 | ForEach-Object {
    pwsh -NoProfile -ExecutionPolicy Bypass -File $_.FullName
}
```

Набори перевіряють AST-аналіз, шлюз виконання, маскування секретів, запис сценаріїв, HTTP-помилки й тайм-аути та передавання агентних завдань. Джерелом істини є поточний запуск; у цьому посібнику немає фіксованої кількості успішних тестів.
