# TerminalAI.Aot — керований бінарний C#-модуль .NET 10 для PowerShell

[English](README.md) | **Українська** | [Головна документація](../README.uk.md)

`TerminalAI.Aot` — керований бінарний C#-модуль .NET 10 (скомпільований допоміжний модуль) для TerminalAI на PowerShell 7+ (`net10.0`). Він реалізує командлет `Invoke-AiCommandFast` (аліаси `aif` та `ai-fast`). Він використовує спільну конфігурацію TerminalAI, звертається до Ollama через HTTP, аналізує згенерований PowerShell-код і може передати завдання до `Invoke-AiAgent` основного модуля.

Вбудовані елементи інтерфейсу, статуси, довідка, меню та повідомлення про помилки доступні лише англійською. Спільний параметр `Language` задає бажану мову текстових відповідей моделі для `-Ask` і `-Explain`; він не локалізує інтерфейс модуля та не впливає на генерацію команд без пояснень.

Проєкт націлений на `net10.0`. Назва каталогу `AOT` є історичною: поточний `.csproj` створює звичайну керовану DLL командою `dotnet build` і не містить конфігурації публікації NativeAOT.

## Можливості

- постійний `HttpClient` із `SocketsHttpHandler` для запитів до `/api/generate`;
- AST-аналіз через `System.Management.Automation.Language.Parser`;
- класифікація команд за дев’ятьма категоріями та чотирма рівнями ризику;
- перевірка синтаксису, параметрів, динамічних викликів, splatting і цілей;
- шлюз виконання з підтвердженням небезпечних або невизначених операцій;
- безпечний `-WhatIf` лише для команд, які підтримують `ShouldProcess`;
- маскування відомих форматів секретів перед окремими операціями відображення чи копіювання;
- Win32-буфер обміну та консольний ввід на Windows;
- збереження сценаріїв у UTF-8 із BOM, порівняння змін і захист від перезапису;
- делегування `-Agent` до `Invoke-AiAgent`, якщо основний модуль імпортовано.

> [!IMPORTANT]
> Згенеровані моделлю команди є недовіреним введенням (untrusted input). Завжди переглядайте код перед виконанням. Перевірки AST та симуляція WhatIf є захисними бар'єрами (safety guardrails), а НЕ безпековою пісочницею (security sandbox). TerminalAI перевіряє синтаксис PowerShell, класифікує ризик і запитує підтвердження для операцій високого ризику або невизначених дій.

## Встановлення та імпорт

Основний інсталятор копіює кореневий `TerminalAI.Aot.dll` разом із модулем для PowerShell 7+. Для ручної перевірки збірки:

```powershell
dotnet build .\AOT\TerminalAI.Aot.csproj -c Release
pwsh -NoProfile -Command "Import-Module .\AOT\bin\Release\net10.0\TerminalAI.Aot.dll -Force; Get-Command aif"
```

Якщо DLL уже завантажена в PowerShell, Windows може заблокувати її перезапис. Відкрийте новий процес `pwsh -NoProfile` для перевірки нової збірки.

## Використання

```powershell
aif "знайти файли розміром понад 100 МБ"
aif "показати відкриті TCP-порти" -Execute
aif "отримати адресу шлюзу" -Copy
aif "знайти процеси, що використовують понад 1 ГБ пам'яті" -Alias
aif "як PowerShell передає об'єкти конвеєром?" -Ask
aif "створи сценарій резервного копіювання" -SavePath .\backup.ps1
aif agent "перевір git diff і запусти доречні тести"
```

### Параметри `Invoke-AiCommandFast`

| Параметр | Аліаси | Призначення |
| --- | --- | --- |
| `-Prompt` | позиційний 0 | Текст запиту або підкоманда. |
| `-Model` | — | Модель Ollama для цього виклику. |
| `-Execute` | `-x`, `-y` | Передати результат шлюзу виконання. |
| `-Copy` | `-c` | Скопіювати санітизований результат. |
| `-Explain` | — | Отримати структуроване пояснення. |
| `-Ask` | `-chat`, `-question` | Отримати текстову відповідь замість команди. |
| `-Agent` | `-Autonomous` | Передати завдання до `Invoke-AiAgent`. |
| `-Alias` | `-a`, `-Short`, `-UseAliases` | Використовувати короткі аліаси PowerShell. |
| `-SavePath` | `-Save`, `-OutFile` | Зберегти результат у файл. |
| `-Force` | `-f` | Перезаписати наявний файл без запиту. |
| `-ConfirmInput` | — | Передати відповідь шлюзу виконання; призначено насамперед для тестів. |

Підтримувані керівні підкоманди: `models`, `model <name>`, `lang <en|uk>`, `status`, `config`, `help` та `agent <task>`. Підкоманда `lang` змінює бажану мову текстових відповідей моделі, а не мову інтерфейсу.

### Інтерактивне меню

| Клавіша | Дія |
| --- | --- |
| `Enter` | Виконати через `AotExecutionGate`. |
| `C` | Скопіювати санітизований текст. |
| `I` | Вставити команду в наступний рядок для редагування. |
| `S` | Перемкнути короткі та повні назви командлетів. |
| `W` | Зберегти у файл із попереднім переглядом змін. |
| `X` | Пояснити команду. |
| `A` | Перейти до текстової відповіді. |
| `Esc` | Скасувати. |

## Модель безпеки

Згенеровані моделлю команди є недовіреним введенням (untrusted input). Завжди перевіряйте їх перед виконанням. Перевірки AST та симуляція WhatIf є захисними бар'єрами (safety guardrails), а НЕ безпековою пісочницею (security sandbox). Команди виконуються безпосередньо в сесії PowerShell з правами поточного користувача.

`AotCommandAstAnalyzer` використовує категорії `ReadOnly`, `SystemChange`, `Deletion`, `NetworkChange`, `ServiceOrProcess`, `Registry`, `DiskOrPartition`, `DynamicOrUnknown` та `ExternalProgram`. Рівні ризику: `Low`, `Medium`, `High`, `Critical`.

Синтаксично некоректні команди блокуються. Високий, критичний або невизначений ризик, динамічний виклик та невизначена ціль потребують явного підтвердження. Зовнішнім програмам не додається `-WhatIf`, оскільки TerminalAI не може довести, що вони підтримують семантику `ShouldProcess`.

`AotSecretSanitizer` розпізнає низку поширених ключів, bearer-токенів, параметрів паролів і PEM-блоків. Це детермінований фільтр за шаблонами, тому він не гарантує виявлення секретів невідомого формату.

## Конфігурація

Модуль читає `~/.terminal-ai/config.json`. Основні поля: `OllamaUrl`, `Model`, `Language`, `Temperature`, `TimeoutSeconds`, `UseAliases` та параметри агентного режиму. Значення за замовчуванням і способи зміни наведені в [головній документації](../README.uk.md#-керування-конфігурацією-шрифтами-та-мовою-відповідей).

## Тести

```powershell
Get-ChildItem .\AOT\tests\*.Tests.ps1 | ForEach-Object {
    pwsh -NoProfile -ExecutionPolicy Bypass -File $_.FullName
}
```

Набори перевіряють AST-класифікацію, шлюз виконання, санітизацію секретів, запис сценаріїв, HTTP-помилки й тайм-аути, а також делегування в агентний режим. Фіксовану кількість успішних тестів у документації не наведено навмисно: джерелом істини є поточний запуск.

## Обмеження

- Модуль використовує Win32 для буфера обміну й частини консольної взаємодії, тому він призначений для Windows.
- `aif -Agent` потребує імпортованого основного модуля TerminalAI.
- Фактична затримка відповіді переважно залежить від моделі, обладнання та Ollama; компіляція C# не робить інференс субмілісекундним.
- Паритет із PowerShell-реалізацією потрібно підтверджувати тестами для кожної зміни.
